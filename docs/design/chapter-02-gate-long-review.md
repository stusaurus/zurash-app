# 第2章・第56面長編ゲート研究

本番50面、家修復、セーブ、既存11手の切替式ゲート入門、CPU対戦は変更しない。

## 新しい研究候補「氷扉のむこうへ」
- 5×5盤面、有効21マス、動かせる壁2個、星6個。初期ゲートは閉鎖。
- 既存11手の入門試作と同じ地形に星を2つ増やし、壁移動が増える構成。
- 最短16手、壁操作8回、星取得1/6/7/10/13/16手目。
- 8手目にスイッチを踏んで開き、9手目にゲートのタイルを横断する。
- ゲートを永久閉鎖したルールで全状態探索するとクリア不可能。単なる演出ではない。
- S=16手、A=17〜18手、B=19〜20手。4段階ヒント、Undo、試遊中ベストを継続。
- 最短の数字と必須性は元の `gate-v2.js` の完全BFSで毎回検証。探索予算による中断は「不可能」と扱わない。
