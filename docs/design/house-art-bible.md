# ズラッシュ！ 第1章 美術基準（ハウス・アートバイブル v1）
> ステータス: **デザイン方針の採用**。個別画像の完成承認ではありません。

## 作品の方向性
第1章はトリケンの家（ステージ1〜50）。ゲーム全体は **家 → ご近所 → 村 → 町 → 都市 → 国 → 世界** へ成長する。『ホームスケイプ』型の「パズル初回クリア → ★獲得 → 建築・修復 → 見た目と物語が進行」の循環を参考にしつつ、キャラクター・デザイン・ルールを模倣しない。

ユーザーが選んだ外観の方向は **C：氷×木のファンタジーハウス**。
- 平屋。家として暮らせる暖かさと、雪・氷・結晶の魔法的な輝きを両立。
- 夕方〜夜のあいだ。青紫の雪景色、木の暖色、ランタンと窓の琥珀色の光。
- 木の梁・扉・窓枠・ポーチに、つらら・氷の結晶・透明感のある装飾。
- 立体感のある高品質2.5D。写真のような背景だけが突出しないよう建物・キャラ・家具と光源を統一。

## 変更してはいけない既存構造
PR #5 のシーン設計 `src/house-scenes.js` / `HOUSE_PLAN` を基準とする。
- 正面（南）に玄関。西がリビング、東がキッチン・庭、北が寝室。
- 平屋で階段を追加しない。屋根の小窓は屋根裏の明かり取りであり2階ではない。
- 外観と玄関で扉・外壁・照明の修復IDと選択番号を共有する。
- 玄関の内部から見た左右は外観と逆。既存シーンの窓・ドアの相対位置を崩さない。
- トリケンは現行承認済み素材を使用。デザイン見本に混入した別キャラクターは採用しない。

## シーン単位で設計・実装
外観はホーム、玄関・リビング・キッチン・寝室・庭は独立したシーン。1枚の断面パネルで全部を表現しない。
背景、変更可能なオブジェクト、タップ判定、修復状態、UIを分ける。背景1枚に完成済みのドア・窓・キャラクターを焼き込まない。

## 修復前/修復後の整合
- 修復前: 古びたが住みたくなる家。部分的な欠け、剥がれ、消えた灯り。
- 修復後: 形と素材に異なる **3案**。同じ設置位置・輪郭のインターフェイスに収まる。
- 建設中: 資材・短いアニメーション。既存セーブ仕様を壊さない。
- 描画の接合: 影・光・雪被り・壁の奥行きは前後のレイヤーで統一する。
