# 第58面・研究候補「閉じた氷扉の星」

## 設計目的
第57面は現行ルールでは3回切替必須だが「開けた扉が閉じなくても17手で解ける」問題があった。第58面はゲートの**閉鎖自体を停止位置として使わなければ全星を集められない**ことを目標として再設計。

## 最短解の構造
5×5盤面、有効18マス、星6個、動く壁2個。
- 最短17手。壁を動かす操作8回。S=17手、A=18〜19手、B=20〜22手。
- 2手目でゲートを開き、7つの候補経路ではなく17手の検証済み証明ルートを使用。
- 16手目でスイッチに止まって閉じ、17手目に上へ滑る。ゲートマス5が壁になるので手前のマス10で停止し、**最後の星**を獲得。
- 星取得は4、5、8、10、14、17手目。

## 実装上の厳密な証明
正規 `solveGate` が最短17手を証明。さらに同じ `gateSuccessors` を使った2つの反実仮想を**完全探索**する。

1. **開いたら閉じない**：ゲート開放後、スイッチを踏んでも開いたまま。全状態を探索するとクリア不可能（独立探索で5,186状態を探索して打ち切りではなく完全終了）。
2. **再閉鎖後のゲートによる停止を禁止**：少なくとも1度開いたあと、閉じているゲートの1マス手前で止まる遷移だけを禁止。それ以外の通常アクションは維持。完全探索してもクリア不可能（独立探索約9,705状態）。

よって第57面と異なり、**「扉が閉じて障害物になること」そのものが攻略の鍵**。ただし機械的な証明はプレイの面白さの保証ではない。
