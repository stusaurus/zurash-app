# ズラッシュ！ 第2章 STEP39｜CPU難易度の実測監査

## 目的と開発方針

ゲームシステム完成前にはデザインを全面変更しない。既存の7×7・先取3個のCPU試遊で、「れんしゅう」「ふつう」「じっくり考える」の難易度が行動の違いとして成立するか検証する。

## 実測方法（2026-11-05）

- 対象: `src/engine.js` と `src/ai.js` の既存合法手・評価・探索、および `src/boss-cpu-settings.js` の3段階
- 条件: 既存の回転対称7×7盤面 `LAYOUTS[0..2]`、各盤面2種類の固定乱数条件、各組み合わせで先攻/後攻を交換
- 対戦数: 3難易度から2者を選ぶ3組 × 3盤面 × 2乱数 × 先後2 = **36局**
- 1局の上限: 80手。勝者不在で上限に達した局は勝敗や引き分けに**数えず**「未決着」とする
- 実行: 同一リポジトリのJSゲームロジックを隔離されたV8環境で再評価。DOMやセーブ操作、CPU研究版ルールは使用しない。Node.js GitHub Actionsでも同じ条件の再実行を追加
- 再現: `node scripts/boss-cpu-benchmark.js --full`。個別試合・処理時間・未決着理由のJSONと表のMarkdownを `reports/` に出力する

## 測定結果（36局）

| 対戦 | 左側の勝ち | 右側の勝ち | 未決着 | 決着局の平均手数 |
| --- | ---: | ---: | ---: | ---: |
| れんしゅう vs ふつう | 0 | 12 | 0 | 11.33 |
| れんしゅう vs じっくり考える | 0 | 12 | 0 | 13.50 |
| ふつう vs じっくり考える | 3 | 9 | 0 | 14.08 |
| **合計** | | | **0** | **12.97** |

36局すべてが決着。勝ち数合計は、れんしゅう0、ふつう15、じっくり考える21。混合難易度の勝敗による先攻勝ち15・後攻勝ち21は、**同じ強さ同士の先攻後攻公平性の証明ではない**。

現状の3段階は、少数の対局の範囲で期待どおりの性能差がある。より強いAIが必ず勝つわけではなく、ふつうもじっくり考えるに3勝した。

## 解釈の注意

- **これは対AI性能の比較であり、人間が「簡単・ふつう・難しい」と感じるかの評価ではない。** 人間試遊と説明のわかりやすさが別途必要。
- 特に探索AI対ふつうの9勝3敗は12局しかない。勝率の精密な推定には追加の乱数と盤面が必要。
- 80手上限は分析上の打ち切りであり、ゲーム本編に手数上限や引き分け判定を追加していない。
- CPU対戦は第2章の独立試遊。星・結晶・家づくりの記録には影響しない。
- 今後のステージ統合や演出の大幅なデザイン変更は保留。システムの完成・安定性・試遊を先に進める。
