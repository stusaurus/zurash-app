# 第57面「三度ひらく氷扉」研究候補

## 検証対象
5×5（有効21マス）、星7個、移動壁2個、切替式ゲート1個・スイッチ1個。最短19手。壁移動8回、取得は1/3/5/9/13/15/19手目。ゲートは7手目に開き、16手目に閉じ、18手目に再び開く。

既存の第56面（11手入門・16手長編）、第1章50面、家づくり、セーブ、CPU対戦は変更しない。

## 必須性の厳密な意味

`verifySwitchMinimum` はゲートの開閉回数を探索状態に含めた幅優先探索を行う。最大2回までの全到達可能状態を調べ尽くしたときだけ「3回以上必要」と判定し、時間切れ・状態数上限は未検証とする。正規の `solveGate` で最短19手を別途証明し、実操作ルートでちょうど3回の切替を示す。

**注意：** 切替を発生させないルール（閉鎖固定）と「一度開けば閉まらない」という別ルールは異なる。研究用の独立探索では、開放維持の別ルールで17手の解が見つかった。したがって、閉じることで新しい停止位置を作る戦略が必須という証明ではない。本候補は「スイッチを3回踏まないとクリアできない」ことの証明であり、「開閉が戦略的に優れている」「必ず面白い」ことの証明ではない。特に16〜18手目に往復操作の退屈さがないか人間試遊で評価し、不適切なら盤面を差し替える。

## 試験
- 正規 `solo-v2-gate` エンジンによる最短19手BFS、19手証明ルートの合法再生。
- 最大2回切替禁止探索の完全終了、3回では解が存在することを検証。
- ゲートが閉じた際の4段階ヒントの表記修正。
- Chromium/WebKit × 320/390pxで、タップ19手、7/16/18手目の開閉、Undoからの復旧、Sランク、横スクロールなし、localStorage不変更を検証。

正式キャンペーンへの登録・mainマージは禁止（研究用Draft）。
