# 第59面「時空の氷海と七つ星」検証記録

## 盤面と物語
- 8×5 / 有効25マス、星7個、動く壁2個、ゲートとスイッチ各1、ワープクリスタル1回、ポータル1組。
- 地続きの5列と離れ小島2列は1列の海で完全分離。島へはワープでしか入れない。
- ゲートを開けて本土側の6個を回収し、最後に孤島の星1個へワープする。
- 最短20手（S）、A=21〜22手、B=23〜25手。最短解の8手目にゲート開放、20手目で唯一のワープ。壁移動9回。
- ワープを早く使用すると本土に戻れない。Undoまたは「最初から」で復帰できる。

## 必須性
- 正規 `solveGate` により最短20手を全状態BFSで証明。
- 正規 `gateSuccessors` の**ワープ行動のみ禁止**した完全探索でクリア不可能。探索予算到達は必須とは認定しない。
- 正規 `solveGate({locked:true})` により、ゲート永久閉鎖の完全探索でもクリア不可能。両方がそれぞれ必須である。
- 独立探索の予備結果：最短探索38,106展開、ワープ禁止31,384展開、ゲート永久閉鎖409展開。これらはCI正規結果ではないため別途正規Nodeテストを必須とする。

## デザイン判断
第58面は閉じたゲートの停止位置、第59面は**ゲートの攻略を終えてから離れ小島へ飛ぶクライマックス**を狙う。ゲートとワープがそれぞれ必須なのは証明できるが、ゲートの開閉とワープが同一の一手に連動する構造ではない。人間試遊で終盤のワープが単なる作業に感じられる場合は正式採用せず入れ替える。
