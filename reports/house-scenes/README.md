# 第4段階：外観・玄関のシーン制作

PR #3 (015cc0b6695249648cee1273a5a8a403ecc40900) を基点にした独立した表示モジュール。外観を起点に、玄関・リビング・キッチン・寝室・庭へ移動する。今回の美術制作対象は外観と玄関。残る4シーンは従来描画を部屋ごとに拡大して維持し、承認後に同じ美術水準へ展開する。

## 空間と描画

- 平屋の家。南中央に玄関、西にリビング、東にキッチン、北に寝室、東の敷地に庭。階段は設けない。屋根の小窓は屋根裏の明かり取り。
- 外観は南東から、玄関は北から南を向く。外の左にあるリビングの窓は、中では右に来る。玄関から左がキッチン、右がリビング。同じ扉の内側では取っ手を反転する。
- `src/house-scenes.js` が形状とシーンへの入口を定義。外観と玄関の扉・壁・照明には、同じ修復ID・装飾番号を使う。片方で変更すれば両方に反映される。
- 解像度に依存しないSVGで、雪、山並み、屋根、梁、窓枠、カーテン、床板、ラグ、玄関ベンチ、靴、コート、植物を描く。元の正式画像 `assets/triken-orange-80.png` をそのまま使用。
- 修復前は割れ・剥がれ・折れた照明、建設中は足場と短いアニメーション、完成後は選んだ形状・素材を描画。低減モーション設定ではアニメーションなし。

| 修復 | デザイン0 | デザイン1 | デザイン2 |
| --- | --- | --- | --- |
| 扉 | オークのアーチ扉・真鍮 | 格子ガラス・塗装木枠 | 丸窓・縦羽目板・銅 |
| 外壁 | 漆喰・露出木梁 | シダーの横板張り | 石灰岩・砂岩の石積み |
| 玄関灯 | 真鍮の角形ランタン | 銅のベル型シェード | 乳白ガラスの球形灯 |

装飾カードは実際の形を表すサムネイルと素材名を表示。選択は無料で何度でも変更可能。玄関灯と外灯は同じ照明シリーズを内外に取り付ける修復。外壁修復は内側の壁仕上げも含み、新しい有料タスクを増やさない。

## 互換性と予算

50面の配置、攻略証明、10/20/30面のアイテム解放、15タスクと40個の星、v2保存形式、旧v1移行を変更しない。旧装飾番号0/1/2は保持し、玄関3タスクのみ新しいデザインに対応づける。他の部屋は従来の色選択を維持する。

家のシーン選択とスクロールは表示上の状態で、再読み込みすると外観へ戻る。修復・装飾・支出履歴は保存される。建設中に再読み込みしても、支払い済みの修復を再開し二重徴収しない。

50面クリアで50個獲得、必須修復40個、残り10個。家を直さず50面まで進められる。家の完了イベントを維持する。研究用の旧町モードの検証結果（9個支出・41個残り）と、この家モードの会計（40個支出・10個残り）は別の検査である。
